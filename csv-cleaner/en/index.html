FAQ

Is my file uploaded?
No. The file is read with the browser's built-in FileReader and processed entirely in your device's memory. It works offline.
The preview looks like mojibake — what now?
The file is probably GBK-encoded but was read as UTF-8. Set Encoding to "Auto" (or GBK) and hit Re-parse.
What is a delimiter?
CSVs use commas, but some tools export semicolons or tabs. "Auto-detect" picks whichever symbol appears most in the first line — you can usually ignore this setting.
How large a file can it handle?
Pure in-memory frontend processing: smooth up to ~100k rows. Larger files are best split first.
