CSV 去重的 3 种方法：Excel / Python / 在线工具（含优缺点对比）

从"选中几万行手动删"到"一个脚本 3 秒搞定"，去重这件事的效率差距可以达到 100 倍。这篇讲三种方法的适用场景和操作步骤。

方法一：Excel 条件格式标记法（适合 < 1 万行）

1. 选中数据区域 → 开始 → 条件格式 → 重复值

2. 重复行会高亮显示 → 手动筛选删除

优点：零门槛，所见即所得

缺点：超过 1 万行会卡；只能标记不能自动删；关闭文件后标记消失

适合：一次性处理小文件，或需要人工确认哪些该删

方法二：Python 脚本批量法（适合 > 1 万行 或 需要重复执行）

import pandas as pd
df = pd.read_csv('input.csv', encoding='utf-8')
df_cleaned = df.drop_duplicates()
df_cleaned.to_csv('output.csv', index=False, encoding='utf-8-sig')
print(f'原始 {len(df)} 行 → 去重后 {len(df_cleaned)} 行')

优点：10 万行秒完成；可反复执行；逻辑可审计

缺点：需要 Python 环境；编码问题要手动处理（GBK/UTF-8）

适合：定期 recurring 的去重需求，或数据量大到 Excel 卡死

方法三：在线工具一键法（适合临时需求 + 不想装环境）

用支持自动去重 + 编码识别的在线工具——拖进去就能用，不需要装任何环境。

优点：零门槛；浏览器里完成；文件不上传服务器

缺点：单次处理量受浏览器内存限制（通常 10 万行以内）；不能保存处理逻辑供下次复用

适合：临时收到一个文件要去重，或不想为此装 Python

选择建议

一次性小文件 → Excel 标记（最快出结果）

定期重复 + 大文件 → Python 脚本（一劳永逸）

临时 + 不想装环境 → 在线工具（注意选本地处理的）

→ 打开 CSV 清理器（免费 · 纯本地 · 自动识别编码 · 文件不上传）
一个进阶技巧：如果你定期收到同样格式的 CSV 需要清洗，别每次手动操作——把清洗逻辑写成一个脚本或用支持"处理规则保存"的工具，下次一键执行。这就是"把重复劳动变成资产"。
